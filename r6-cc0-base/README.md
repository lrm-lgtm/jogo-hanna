# R6 — experimento de base rigada de qualidade superior

Este laboratório **não substitui a Hanna**. Avalia se um modelo 3D CC0, já construído e rigado por outra ferramenta, dá acabamento de rosto/cabelo melhor que o avatar procedural Blender R5.

- Modelo: **HairSample_Female.vrm** (VRoid Studio beta), modelo de demonstração CC0 conforme a [documentação oficial](https://vroid.pixiv.help/hc/en-us/articles/4402614652569-Do-VRoid-Studio-s-sample-models-come-with-conditions-of-use).
- Espelho de download: [madjin/vrm-samples](https://github.com/madjin/vrm-samples), commit `e16eb187100149a315ad92c3c9968f1d5baa6c7d` arquivo `vroid/beta/HairSample_Female.vrm`, Git blob `0e5235f9a7972fbcbceb74960479b208c27a8707`.
- A licença CC0 corresponde somente ao modelo amostra especificamente mencionado, não ao conjunto inteiro VRoid.
- A troca de extensão VRM → GLB mantém o contêiner glTF 2.0 para o Babylon; o MToon específico do VRM pode ter incompatibilidades, e esse é parte do teste.
- Fotos reais da criança, referência ilustrada e dados pessoais **não são enviados** ao provedor.
- O modelo é apenas um **candidato a base estilizada**; proporções, figurino, idade aparente e mochila polvo continuam requisitos independentes do avatar final.

**Gate**: verificar que carrega no navegador, que tem esqueleto, e inspecionar screenshot real. Não marcar visual premium sem comparação e adaptação.
