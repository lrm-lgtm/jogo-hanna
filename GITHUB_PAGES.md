# Casa da Hanna no GitHub Pages

A versão atual está preparada para publicação via GitHub Actions.

## Publicação
No repositório, abra **Settings → Pages** e em **Build and deployment → Source** selecione **GitHub Actions**.

Depois, o workflow `Deploy Casa da Hanna` publica automaticamente cada atualização do branch `main`.

Endereço esperado:
https://lrm-lgtm.github.io/jogo-hanna/

## iPhone
Abra o endereço no Safari → Compartilhar → Adicionar à Tela de Início.

## Offline
A interface e a lógica são pré-cacheadas. Babylon.js e modelos 3D externos são armazenados em runtime depois da primeira abertura online.
